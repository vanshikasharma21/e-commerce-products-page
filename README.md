# 🛒 E-Commerce Products Page

A responsive and interactive **E-Commerce Products Page** developed using **HTML, CSS, and JavaScript**. The application retrieves real-time product data from the **Fake Store API** and presents it through a clean, modern, and user-friendly interface.

## ✨ Key Features

* Real-time product fetching with Fake Store API
* Responsive design for desktop, tablet, and mobile
* Dynamic product cards with image, title, price, category, and rating
* Smooth and intuitive user interface
* Well-structured and maintainable codebase

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (ES6)
* Fake Store API

## 🚀 Getting Started

1. Clone this repository.
2. Open the project folder.
3. Launch `index.html` in your preferred web browser.

## 🎯 Learning Outcomes

* Working with REST APIs using JavaScript Fetch API
* Handling asynchronous data with `async/await`
* Rendering dynamic content in the DOM
* Building responsive layouts with HTML and CSS
* Improving frontend development skills through API integration
